# Azure CDN (Microsoft.Cdn)

> Azure Content Delivery Network caches static web content at edge locations worldwide. Its management
> API — the Microsoft.Cdn Azure Resource Manager resource provider — creates and operates CDN profiles,
> endpoints, origins, custom domains and WAF policies, and also serves the Azure Front Door Standard and
> Premium resources. IMPORTANT: Azure CDN Standard from Microsoft (classic) is retiring on 2027-09-30
> and stopped accepting new instances in 2025. Microsoft directs new work to Azure Front Door.

## Things an agent must know before acting

- 56 of 115 operations are LONG-RUNNING. They return `202 Accepted` with an `Azure-AsyncOperation` or `Location` polling URL. The resource is not in its final state when the call returns.
- There is NO `Idempotency-Key` header. PUT and DELETE are replay-safe by ARM resource semantics (30 operations); the 45 action POSTs and PATCHes — purge, load, start, stop, migrate, upgrade — are not.
- `Profiles_Delete` cascades to every endpoint, origin and custom domain under the profile and has no restore path.
- The migration to Azure Front Door is reversible: `Profiles_Migrate` can be undone with `Profiles_MigrationAbort` at any point before `Profiles_MigrationCommit`.
- Throttling is a token bucket: 250 reads / 200 writes / 200 deletes per subscription per region, refilling at 25 / 10 / 10 per second. On exhaustion you get `429` with `Retry-After`. Watch `x-ms-ratelimit-remaining-subscription-reads|writes|deletes`.
- Errors are NOT RFC 9457. The envelope is `{"error": {"code","message","target","details","additionalInfo"}}`.

## Resource model

- [Data model](data-model/microsoft-azure-cdn-data-model.yml)
- Root: `Profile`. Its SKU decides which of two families it belongs to.
- Classic CDN family: Profile > Endpoint > Origin, OriginGroup, CustomDomain; plus CdnWebApplicationFirewallPolicy.
- Azure Front Door family: Profile > AFDEndpoint > Route; AFDOriginGroup > AFDOrigin; AFDDomain, RuleSet > Rule, Secret, SecurityPolicy.
